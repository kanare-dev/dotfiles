# zsh/CLAUDE.md

`zsh/.zshrc`（`~/.zshrc` へリンクされる）を編集するときのルール。

## 構成

`# ====` 区切りのセクションごとに「思想:」コメントで意図を書くスタイル。追記時もこの形式に合わせる。セクションは読み込み依存の順（PATH → Environment → … → Plugins）に並べる。

## コメントのルール

- 見出しは `Name（日本語の役割）`。直後に `# 思想:` を1文で書き、非自明な理由だけ `# - ` の箇条書きで補う。
- 「外部ツールは存在するときだけ有効化する」は冒頭の Overview に集約済み。各セクションで繰り返さない。
- コメントは「何をするか」ではなく「なぜそうするか」を書く。自明なものは書かない。
- `setopt` / `alias` の並びは行末コメントを揃える。ロジックは直前の行にブロックで書く。
- 常体で句点なし。日本語と英数字の間は半角スペース、括弧は全角。コード片はバッククォートで囲む。
