# Neovim 操作マニュアル

この設定 (`init.lua` / `lua/`) での操作方法まとめ。

## Leader キー

`<leader>` は **スペースキー** に設定済み（`core.lua`）。以下の操作はすべて
「スペースを押してから離し、次のキーを押す」という意味。

## ファイルツリー（neo-tree）

| キー | 動作 |
| --- | --- |
| `<leader>e` | ツリーの開閉（現在編集中のファイルを選択した状態で開く） |
| `<leader>o` | ツリーにフォーカス移動 |

ツリー内での操作:

| キー | 動作 |
| --- | --- |
| `l` | ファイル/ディレクトリを開く |
| `h` | ノードを閉じる |
| `<space>` | ノードの展開/折りたたみ |
| `P` | プレビュー（フロート表示） |

## ウィンドウ移動

ツリーとエディタなど、ウィンドウ間のフォーカス切り替えはVim標準の操作を使う。

| キー | 動作 |
| --- | --- |
| `<C-w>h` / `<C-w>l` | 左/右のウィンドウへ移動 |
| `<C-w>j` / `<C-w>k` | 下/上のウィンドウへ移動 |
| `<C-w><C-w>` | 直前のウィンドウとトグルで切り替え |

`<C-w>` は「Ctrl+wを押してから離し、次のキーを押す」という意味（Vim標準のウィンドウ操作プレフィックス）。

## LSP

`LspAttach` 時にバッファローカルで有効になる。

| キー | 動作 |
| --- | --- |
| `gd` | 定義へジャンプ |
| `gD` | 宣言へジャンプ |
| `gr` | 参照一覧 |
| `gi` | 実装へジャンプ |
| `K` | ホバー（ドキュメント表示） |
| `<leader>rn` | リネーム |
| `<leader>ca` | コードアクション |
| `[d` / `]d` | 前/次の診断へ移動 |
| `<leader>d` | 診断をフロート表示 |
| `<leader>q` | 診断一覧をlocation listに表示 |

## Telescope（ファジーファインダー）

| キー | 動作 |
| --- | --- |
| `<leader>ff` | ファイル名で検索 (find_files) |
| `<leader>fg` | 全文検索 (live_grep, 要 ripgrep) |
| `<leader>fb` | 開いているバッファ一覧 |
| `<leader>fh` | Neovimヘルプタグ検索 |

Telescope内の操作:

| キー | 動作 |
| --- | --- |
| `<C-j>` / `<C-k>` | 候補を下/上に移動（insertモード時） |
| `<CR>` | 選択した候補を開く |
| `<C-c>` / `<Esc>` | 閉じる |

## Git（gitsigns）

バッファ内でGitの変更箇所（hunk）を操作する。

| キー | 動作 |
| --- | --- |
| `]h` / `[h` | 次/前のhunkへ移動 |
| `<leader>hs` | hunkをステージ |
| `<leader>hr` | hunkをリセット |
| `<leader>hp` | hunkをプレビュー |
| `<leader>hb` | 行のGit blameを表示 |

## その他

| キー | 動作 |
| --- | --- |
| `<Esc>` | 検索ハイライトを消す (`:nohlsearch`) |

## プラグインの更新（lazy.nvim）

プラグインの更新は Neovim 内で `:Lazy update` を実行して行う。

| コマンド | 動作 |
| --- | --- |
| `:Lazy` | プラグイン管理画面を開く |
| `:Lazy update` | 全プラグインを最新版へ更新する |
| `:Lazy restore` | `lazy-lock.json` の記録どおりのバージョンへ戻す |

運用の流れ:

1. `:Lazy update` で更新し、動作に問題がないか確認する。
2. 更新で `lazy-lock.json` が書き換わるので、リポジトリにコミットする（例: `chore(nvim): lazy-lock.json のプラグインを更新`）。
3. 不具合が出たら `:Lazy restore` で `lazy-lock.json` の状態に戻す。

`lazy-lock.json` は `~/.config/nvim/` 配下のリンク経由でリポジトリ内のファイルを直接更新する。
別マシンでは `git pull` 後に `:Lazy restore` を実行すると、同じバージョンに揃えられる。

## 補完（blink.cmp）

`preset = "default"` のため、標準的な補完キーバインド（`<C-space>`で候補表示、`<Tab>`で確定など）に従う。
